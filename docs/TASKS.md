# Task breakdown

Four phases. Phase 1 runs as four parallel Claude Code sessions, each in its own git worktree and branch, each owning
its own directories so branches merge without conflicts. Phase 0 pre-declares every dependency and the contract in
`src/clipforge/schemas.py`, so Phase 1 branches never edit `pyproject.toml`, `schemas.py`, `db/` or `config.py`. If a
branch truly needs a contract change, it writes the proposed change to `docs/contract-requests/<branch>.md` and stubs
locally; Phase 2 resolves it.

### Notes from Phase 0 for Phase 1 sessions
- `cf` commands owned by a later phase call a fixed function (`clipforge/cli.py` `TARGETS`; signatures are in each
  package's `__init__.py` docstring). Implement that function in your package; don't edit `cli.py`.
- `tests/compliance/` xfail tests name the function they wait for. If your module makes one pass (strict XPASS
  fails the run), delete **only that test's xfail marker** in your branch and say so in the PR. Change nothing else
  in `tests/compliance/`.
- `mediapipe` and `faster-whisper` are installed on Linux only (no Intel-macOS wheels). Import them lazily and use
  `pytest.importorskip` in tests; they run in Docker and CI. The Mac has no ffmpeg unless you install it; tests
  needing it must skip when `shutil.which("ffmpeg")` is None.
- DB rows: change `state` only via `clipforge.db.transition()`; datetimes must be timezone-aware.
